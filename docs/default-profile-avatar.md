# Default profile avatar

Generated with the built-in imagegen tool on 2026-11-07.

- Asset: `app/static/images/default-profile-avatar.png`, 256 × 256 PNG.
- The original generated portrait is retained in the local imagegen output directory. The web asset is resized with macOS `sips`.
- Used by the account menu and profile sidebar through `partials/default-avatar.html`.
- Motion is implemented in `default-avatar.css`: one short greeting and a hover/focus tilt, disabled for reduced motion.

## Generation prompt

Use case: stylized-concept. Asset type: default profile portrait for Preptiva, an interview practice web app with an orange and white visual identity. Create one polished, appealing 3D editorial clay-style human avatar, androgynous young adult, warm medium skin tone, short softly waved dark brown hair, friendly small smile, kind open dark eyes, no glasses, no facial hair, no jewelry. A simple burnt-orange crewneck sweatshirt with a cream collar. Tasteful soft matte surfaces, gently sculpted features, natural proportions with slightly larger head for legibility, refined soft studio light, no plastic shine. Centered close-up head-and-shoulders portrait facing almost straight forward with a very slight head tilt, head and hair entirely in frame. It must read clearly as a welcoming account avatar at 36px and 88px. Square 1:1 composition, subject occupies about 85 percent of height, with small breathing room above head. Warm pale peach seamless background, no objects, no scene, no text, no logos, no decorative ring, no watermark. Deliver a single finished portrait, not a grid, mockup or UI.
